About HealthSecure

Intelligent Insurance Estimation Made Simple

HealthSecure is a machine-learning-based academic application designed to estimate health insurance premium amounts using personal and health-related information.

Traditional underwriting relies on manual actuarial tables that lack transparency. HealthSecure demonstrates how modern tree-based regression algorithms evaluate nonlinear relationships across seven core risk factors to predict annual medical claim charges accurately.

🎂 Age (18-100) ⚧ Gender ⚖️ Body Mass Index (BMI) 🚬 Smoking Status 👨‍👩‍👧 Dependents / Children 📍 Geographic Region 💼 Annual Stated Salary
Academic Project Notice: This is an academic project and the prediction is an estimated result, not an official insurance quotation or guaranteed maturity contract.

Workflow Architecture

How HealthSecure Works

Our platform streamlines actuarial machine learning into four transparent, user-friendly steps from data collection to tailored policy exploration.

Step 01

Enter Your Details

User provides personal, health, and lifestyle information including age, BMI, smoking status, and income.

Step 02

Machine Learning Analysis

The trained ensemble ML model evaluates nonlinear relationships, demographic risks, and interaction terms.

Step 03

Premium Prediction

The system generates an estimated annual insurance premium along with financial sustainability ratios.

Step 04

Plan Matching

The system compares the predicted premium with sample plans in MySQL and displays the closest three options.

Actuarial Input Features

What Does HealthSecure Analyze?

The machine learning model is trained on seven validated features to capture clinical risk and financial affordability.

🎂

1. Age

Chronological age (18 to 100 years) used as an input feature reflecting demographic health morbidity curves.

Continuous Numerical
⚧

2. Gender

Demographic indicator (Female / Male) encoded via One-Hot encoding to account for gender cohort risk patterns.

Categorical (Binary)
⚖️

3. Body Mass Index (BMI)

Body Mass Index (10 to 60 kg/m²) information used as one of the primary quantitative clinical risk features.

Continuous Numerical
🚬

4. Smoking Status

Tobacco usage status (Smoker / Non-smoker), recognized by the model as the single largest financial risk driver.

Categorical (Binary)
👨‍👩‍👧

5. Children / Dependents

Number of dependents (0 to 10) covered under the policy, impacting family medical coverage requirements.

Discrete Integer
📍

6. Geographic Region

Geographical territory (Northeast, Northwest, Southeast, Southwest) capturing regional healthcare provider cost variations.

Categorical (4-Class)
💼

7. Annual Salary / Income

Annual stated earnings benchmark used to calculate the Premium-to-Income affordability ratio (≤ 10% target).

Application Architecture

Designed With User Privacy in Mind

HealthSecure adheres to modern software security standards to safeguard member records, demographic information, and estimation histories.

🔒

Scrypt Password Hashing

User credentials are encrypted using Werkzeug's implementation of Scrypt and PBKDF2 with unique cryptographic salts.

🛡️

Session Management

Protected Flask HTTP sessions with secure cookies and route decorators ensuring unauthenticated access prevention.

🗄️

Parameterized SQL Queries

Full database abstraction through SQLAlchemy ORM, defending against SQL Injection vulnerabilities completely.

👤

Multi-Tenant History Isolation

Regular users can only view, simulate, and export their private estimates; cross-user data leakage is strictly prohibited.
