# Dataset location

Download the Medical Cost Personal Dataset and save its CSV file here as:

`insurance.csv`

Current file source: [Medical Cost Personal Datasets — Kaggle](https://www.kaggle.com/datasets/mirichoi0218/insurance). The checked-in CSV was downloaded from the public GitHub mirror at https://github.com/krish1407/Medical-Cost-Personal-Datasets/blob/master/insurance.csv.

Required columns:

`age, sex, bmi, children, smoker, region, charges`

Do not commit personally identifiable or sensitive health data to a public repository. The application can use the generated demonstration data when this CSV is absent; use a real, approved dataset before reporting model results.
